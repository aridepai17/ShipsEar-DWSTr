# ShipsEar-DWSTr

ShipsEar-DWSTr is a full-stack maritime acoustic classification platform. Powered by a custom Depthwise-Separable Convolution and Transformer model, it classifies 12 vessel types from the ShipsEar dataset. The Next.js and FastAPI app visualizes 75ms audio slices using an interactive waveform, log-mel spectrogram, and prediction timeline.
